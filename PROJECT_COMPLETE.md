## Deployment Strategy

### Blue-Green Deployment
```
Blue (Current)  ←→  Green (New)
100% traffic         0% traffic
v1.0.0              v1.1.0

After deployment:
Green handles 100% traffic
Blue can be safely decommissioned
Instant rollback if needed
```

### Gradual Rollout (6 hours)
```
T+0-15:   Setup (build, test, deploy)
T+15-75:  Canary (10% for 1 hour)
T+75-195: Phase 2 (25% for 2 hours)
T+195-375: Phase 3 (50% for 3 hours)
T+375-390: Phase 4 (100%)

Each phase: Decision gate (proceed or rollback)
```
